# 2026-11-10 — 完整實驗室物件圖清理、檢索驗證與靜態語意圖匯出

### 本次目標

- 保留官方 ConceptGraphs 完整實驗室 object map，同時建立不覆寫原始結果的
  curated map。
- 以來源 RGB 影像驗證重複節點與錯誤標籤，降低查詢畫面的碎片與誤判。

  portable semantic graph JSON，作為後續 ROS 2 與 Nav2 的資料介面。

### 完成內容

#### 1. 建立固定的 open-vocabulary retrieval benchmark

- 新增 `benchmark_object_queries.py`，一次載入 CLIP 後執行多筆查詢，輸出：
  - Hit@1；
  - Hit@k；
  - mean reciprocal rank（MRR）；
  - 每筆查詢的完整排序與穩定 object ID。
- 建立 `lab_verified_benchmark.json`，包含 12 筆經來源 RGB 與 mask 驗證的
  literal／descriptive queries：
  - Rubik's cube；
  - panda plush toy；
  - cardboard box；
  - computer monitor；
  - office chair；
  - reusable water bottle。
- 在最終 v2 map 上的 CPU 回歸結果：
  - evaluated queries：`12/12`；
  - Hit@1：`1.0`；
  - Hit@10：`1.0`；
  - MRR：`1.0`。
- 上述結果只代表這 12 筆人工驗證查詢，不代表整個實驗室所有 322 個節點的
  general accuracy。

#### 2. 非破壞式 object map 清理

- 新增 `curate_object_map.py`，從官方 post map 建立獨立 curated map，不覆寫
  原始結果。
- 保守條件：
  - observation count `>= 3`；
  - 3D point count `>= 50`；
  - 不使用 hard label-purity deletion。
- 節點由 `349` 減少為 `332`，移除 17 個低證據小碎片。
- 每個保留節點新增穩定 `source_object_id`；後續 map list index 即使因過濾
  改變，查詢、關係與人工標註仍能對回原始節點。

#### 3. 重複節點候選與人工審查

- 新增 `find_duplicate_candidates.py`，綜合：
  - CLIP feature cosine similarity；
  - 3D AABB containment；
  - symmetric point-cloud overlap。
- 共產生 12 組候選，逐組回查來源 RGB、mask 與 bounding box：
  - 10 組確認為同一實體並合併；
  - 2 組為互相污染的 table/cabinet/keyboard 區域，拒絕合併。
- 新增 `apply_reviewed_merges.py`，只套用
  `lab_duplicate_review.json` 中的人工決定，並保留所有
  `merged_source_object_ids`。

### 官方程式與本專案擴充的邊界

目前核心 3D semantic mapping 已直接使用官方 ConceptGraphs：

- `scripts/generate_gsa_results.py`：RAM、Grounding DINO、SAM 與 CLIP；
- `slam/cfslam_pipeline_batch.py`：多視角 3D object fusion 與 post-processing；
- 官方 map representation、similarity、DBSCAN 與 object merge 邏輯。

本專案新增的部分是 D455/RTAB-Map dataset bridge、ROS 2、人工品質審查、
benchmark、stable IDs、portable JSON 與 Nav2 前置資料。這些不是取代官方核心，
而是補上官方 Replica-style posed RGB-D workflow 與實驗室 AMR 之間的介面。

官方 `scenegraph/build_scenegraph_cfslam.py` 尚未完整執行。該流程需要舊版
LLaVA-7B-v0 checkpoint、指定 LLaVA source commit、OpenAI GPT-4 API 與 legacy
`openai.ChatCompletion` 介面。目前本機沒有設定 `LLAVA_CKPT_PATH`、
`LLAVA_PYTHON_PATH` 或 `OPENAI_API_KEY`，8 GiB RTX 4060 亦不適合直接載入未量化
7B FP16 模型。後續可在 Thor 上重現官方 caption/refinement/scene-graph 階段。
