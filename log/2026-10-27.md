# 2026-10-27 — 第一版語意空間關係

### 本次目標

- 將只有物件節點的 semantic graph 擴充為包含可驗證空間關係的圖。
- 所有關係必須使用 `map` frame，避免跟隨相機視角改變。

### 完成內容

- 新增獨立的 `relations.py` 幾何關係模組。
- 新增 `near` 關係，使用兩個三維 AABB 的最短表面距離判斷。
- 新增以 `map` X 軸為基準的 `left_of` 與 `right_of` 反向關係。
- 新增以 `map` Z 軸為基準的 `above` 與 `below` 反向關係，並要求 XY 投影重疊。
- 每條 edge 包含計算方式、距離、座標軸或重疊比例等 evidence。
- graph JSON schema 由版本 1 更新為版本 2，並加入座標軸 convention。
- 新增 `object_graph.yaml`，可調整 near、最大配對距離、方向 margin 與 XY overlap threshold。
- `semantic_mapping.launch.py` 與 `d455_mapping.launch.py` 均會載入 relation 設定。

### 驗證結果

- 兩個 ROS 2 packages 均成功完成 `colcon build`。
- 新增 9 項 relation tests；整個 workspace 共 30 項測試通過。
- 測試結果為 0 error、0 failure、0 skipped。
- 兩個 launch file 均可解析，`object_graph.yaml` 已安裝至 package share directory。
- 使用 `d455_static_scene_02` rosbag 完成端到端回放，YOLO、RTAB-Map、三維投影與 graph node 均正常運作。
- 實際 graph 輸出為 `schema_version: 2`、`coordinate_frame: map`、3 個 confirmed nodes 與 5 條 edges。
- 實際關係包含 `near`、`left_of` 與 `right_of`，每條 edge 均包含幾何 evidence。
- 測試使用獨立的 `/tmp` RTAB-Map database，沒有修改原始地圖資料。

### 限制與決策

- `left_of/right_of` 是 map X 軸關係，不代表任意觀察者視角中的左右。
- 第一版不加入 `on` 或 `inside`；目前 noisy AABB 不足以可靠判斷支撐面與容器關係。
- 本次資料中兩個節點的 centroid 僅相距約 9 公分，顯示 duplicate-node 合併仍是下一個必要工作。

### 下一步

1. 改善重複節點合併，避免同一物件產生錯誤的 `near` edge。
2. 在 RViz 加入 relation edge 線段與 relation 文字標籤。
3. 使用 D455 live stream 再驗證不同場景與 threshold。
4. 加入 `on`、`inside` 等需要支撐面或容器判斷的場景關係。

## Grounding DINO + SAM open-vocabulary 前端

### 本次目標

- 將固定類別的 YOLO 前端改為與 ConceptGraphs 方法較接近的文字提示偵測。
- 第一個測試提示為 `box. eraser.`，並保留原有深度投影與 graph 後端。

### 完成內容

- 新增 `grounded_sam_segmentation_node`。
- 使用 `IDEA-Research/grounding-dino-tiny` 依文字提示產生 2D boxes。
- 使用 `facebook/sam-vit-base` 以 boxes 為 prompt 產生 instance masks。
- 加入與 upstream ConceptGraphs-Detect 相同概念的 class-agnostic NMS，降低
  重疊 boxes 造成的 duplicate masks。
- 維持原有 `/concept_graph/segmentation/instance_map` 與
  `/concept_graph/segmentation/detections_json` 介面，後端不需重寫。
- `d455_mapping.launch.py` 預設改用 `detector_backend:=grounded_sam`，並保留
  `detector_backend:=yolo` 作為回歸測試與 fallback。
- 釘選 Transformers 版本與兩個 Hugging Face model revision，降低不同裝置
  重新安裝後的版本漂移。
- `run_d455_mapping.sh` 會先建立 RTAB-Map database 的父資料夾，避免因路徑
  不存在而使核心 `rtabmap` 以 exit code -6 結束。

### 驗證結果

- ROS 2 workspace build 成功。
- 全部 35 項單元測試通過，0 error、0 failure、0 skipped。
- RTX 4060 Laptop GPU 實測可載入 PyTorch 2.11.0+cu128 與
  Transformers 5.21.0。
- Grounding DINO tiny 已完成一次 CUDA FP16 推論。
- SAM ViT-B 已使用一個 bounding box 完成一次 CUDA FP16 mask 推論。
- 兩模型個別推論流程的 PyTorch peak allocated VRAM 為約 1.387 GiB；實際
  ROS pipeline 仍需用 `nvidia-smi` 觀察同時載入與 RTAB-Map 執行時的總顯存。

### 限制與決策

- 此處對齊的是 upstream 的 ConceptGraphs-Detect 2D 前端，不是整套論文
  pipeline；目前尚未加入 RAM/Tag2Text、CLIP region features 與 LLM relations。
- D455 live 驗證時相機實際朝向天花板，畫面中沒有箱子或板擦，因此 0 detections
  是合理結果，不應據此調低 threshold。

### 執行方式

```bash
cd "$HOME/concept-graphs/ros2_ws"
source scripts/ros_env.sh
source install/setup.bash
export CG_AI_SITE_PACKAGES="$HOME/Concept Graph/.venvs/cg-ai/lib/python3.12/site-packages"

./scripts/run_d455_mapping.sh \
  database_path:="$HOME/Concept Graph/concept_graph_data/rtabmap/box_eraser_test.db" \
  delete_db_on_start:=true \
  detector_backend:=grounded_sam \
  text_prompt:="box. eraser." \
  rtabmap_viz:=true
```
