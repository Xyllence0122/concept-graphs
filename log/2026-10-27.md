# 2026-10-27 — 第一版語意空間關係

### 本次目標

- 將只有物件節點的 semantic graph 擴充為包含可驗證空間關係的圖。
- 所有關係必須使用 `map` frame，避免跟隨相機視角改變。

### 完成內容

- 新增獨立的 `relations.py` 幾何關係模組。
- 新增 `near` 關係，使用兩個三維 AABB 的最短表面距離判斷。
- 新增以 `map` X 軸為基準的 `left_of` 與 `right_of` 反向關係。
- 新增以 `map` Z 軸為基準的 `above` 與 `below` 反向關係，並要求 XY 投影重疊。
- 每條 edge 包含計算方式、距離、座標軸或重疊比例等 evidence。
- graph JSON schema 由版本 1 更新為版本 2，並加入座標軸 convention。
- 新增 `object_graph.yaml`，可調整 near、最大配對距離、方向 margin 與 XY overlap threshold。
- `semantic_mapping.launch.py` 與 `d455_mapping.launch.py` 均會載入 relation 設定。

### 驗證結果

- 兩個 ROS 2 packages 均成功完成 `colcon build`。
- 新增 9 項 relation tests；整個 workspace 共 30 項測試通過。
- 測試結果為 0 error、0 failure、0 skipped。
- 兩個 launch file 均可解析，`object_graph.yaml` 已安裝至 package share directory。
- 使用 `d455_static_scene_02` rosbag 完成端到端回放，YOLO、RTAB-Map、三維投影與 graph node 均正常運作。
- 實際 graph 輸出為 `schema_version: 2`、`coordinate_frame: map`、3 個 confirmed nodes 與 5 條 edges。
- 實際關係包含 `near`、`left_of` 與 `right_of`，每條 edge 均包含幾何 evidence。
- 測試使用獨立的 `/tmp` RTAB-Map database，沒有修改原始地圖資料。

### 限制與決策

- `left_of/right_of` 是 map X 軸關係，不代表任意觀察者視角中的左右。
- 第一版不加入 `on` 或 `inside`；目前 noisy AABB 不足以可靠判斷支撐面與容器關係。
- 本次資料中兩個節點的 centroid 僅相距約 9 公分，顯示 duplicate-node 合併仍是下一個必要工作。

### 下一步

1. 改善重複節點合併，避免同一物件產生錯誤的 `near` edge。
2. 在 RViz 加入 relation edge 線段與 relation 文字標籤。
3. 使用 D455 live stream 再驗證不同場景與 threshold。
4. 加入 `on`、`inside` 等需要支撐面或容器判斷的場景關係。

### RealSense 節點崩潰與隔離結果

- 完整 launch 中的 `realsense2_camera_node` 曾在啟動約 5 秒後以

### 已定位的技術根因

- `object_map_transform_node` 有讀取 detection stamp，但目前 TF lookup 使用
  `Time(...)` 的最新 transform，未使用影像拍攝時間。
- Grounding DINO + SAM 存在推論延遲；相機移動時，最新 TF 與影像時間的相機
  pose 不一致，使同一物件被投影至錯誤 map 座標。
- tracker 目前只使用 `label + centroid distance <= 0.35 m` 做 greedy matching；
  座標錯位約 0.78 m 後必然產生 duplicate node。
- `max_missed_frames=-1` 會永久保留所有 tracks，而 `min_observations=3` 又讓
  短暫誤檢太容易升級成 confirmed node。
- 不採用單純放大 matching distance 的 workaround；完整實驗室中可能存在距離
  小於 1 m 的同類物件，放大門檻會錯誤合併不同實體。
